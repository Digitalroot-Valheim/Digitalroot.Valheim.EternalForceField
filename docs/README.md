# Eternal Force Field

## Summary

Build a force field to protect your base.

## License
**GNU Affero General Public License v3.0**

## Details
Added a bone totem to the hammer. It can be found 
under `Defense`, `Furniture` and `Misc`.  
Build a bone totem with a force field to protect your base. The force field 
repels enemy NPCs the same way the force field around the traders works.

This mod is intended for casual play and should be avoided for competitive servers. 

### Build Costs
- Wood x10
- Bone Fragments x10
- HardAntler x1

### Dependencies
- <a href="https://valheim.thunderstore.io/package/denikson/BepInExPack_Valheim/"  target="_blank">BepInExPack Valheim</a>
- <a href="https://github.com/Valheim-Modding/Jotunn" target="_blank">Jotunn (JvL)</a>

### Installation (manual)
1. Download the latest release archive (zip) file.
1. Extract the archive into &lt;Steam Location&gt;\steamapps\common\Valheim\BepInEx\plugins

### Configuration 

| Config         | Category | Data Type | Desc                                  |
| ---            | ---      | ---       | ---                                   |
| ForceFieldSize | Advanced | float     | Configure the size of the force field |
